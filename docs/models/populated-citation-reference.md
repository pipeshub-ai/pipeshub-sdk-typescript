# PopulatedCitationReference

A message's citation reference after the handler populates it: the
stored reference fields, with `citationId` as the id and the cited
document under `citationData`.


## Example Usage

```typescript
import { PopulatedCitationReference } from "@pipeshub-ai/sdk/models";

let value: PopulatedCitationReference = {};
```
