# OAuthBearerTokenError

Error body written by the OAuth bearer-token middleware (RFC 6750 Section 3.1) on routes
that accept only an OAuth access token, such as `GET /oauth2/userinfo`. The same `error`,
`error_description` and `scope` values are repeated in the `WWW-Authenticate` response header.
This is not the standard `ErrorResponse` envelope: `error` is a string.
