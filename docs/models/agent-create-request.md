# AgentCreateRequest

Body of `POST /agents/create`. Fields the gateway validator does not know
(at the top level and inside `models[]`, `webSearch`, `knowledge[]`,
`toolsets[]` and `mcpServers[]`) are dropped before the request reaches the
AI backend; they are not refused.


## Example Usage

```typescript
import { AgentCreateRequest } from "@pipeshub-ai/sdk/models";

let value: AgentCreateRequest = {
  name: "Product Support Agent",
};
```
