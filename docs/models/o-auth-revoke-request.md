# OAuthRevokeRequest

OAuth 2.0 Token Revocation Request (RFC 7009).
Revokes an access or refresh token.


## Example Usage

```typescript
import { OAuthRevokeRequest } from "@pipeshub-ai/sdk/models";

let value: OAuthRevokeRequest = {
  token: "<value>",
  clientId: "<id>",
};
```
