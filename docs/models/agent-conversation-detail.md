# AgentConversationDetail

Reduced conversation view returned by the by-id GET route. This is
not the raw `AgentConversation` document shape: fields like `agentKey`,
`userId`, `orgId`, `conversationSource`, and root-level `messages`
metadata outside the selected slice are omitted.

`sharedWith` is the owner's list of recipients, so it is present only for the
owner. A recipient gets `sharedBy` (who shared the chat) instead.


## Example Usage

```typescript
import { AgentConversationDetail } from "@pipeshub-ai/sdk/models";

let value: AgentConversationDetail = {
  id: "<value>",
  createdAt: new Date("2024-08-11T15:04:12.874Z"),
  isShared: true,
  messages: [
    {},
  ],
  pagination: {
    page: 728517,
    limit: 773583,
    totalCount: 794657,
    totalPages: 349869,
    hasNextPage: true,
    hasPrevPage: true,
    messageRange: {
      start: 455264,
      end: 647137,
    },
  },
  access: {},
};
```
