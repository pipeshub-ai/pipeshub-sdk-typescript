# PatWithSecret

A personal access token as seen by its own creator (one element of
`GET /personal-access-tokens`'s `tokens` array, or the `token` object
returned by `POST /personal-access-tokens` before `accessToken` is added).


## Example Usage

```typescript
import { PatWithSecret } from "@pipeshub-ai/sdk/models";

let value: PatWithSecret = {
  id: "<id>",
  name: "<value>",
  scopes: [
    "<value 1>",
    "<value 2>",
    "<value 3>",
  ],
  createdAt: new Date("2026-04-16T05:55:30.163Z"),
  expiresAt: new Date("2025-02-12T10:00:52.667Z"),
  accessToken: "phpat_eyJhbGciOiJIUzI1NiIs...",
};
```
