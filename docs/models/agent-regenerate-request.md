# AgentRegenerateRequest

Regeneration payload for a scoped agent conversation. The public
gateway requires `chatMode: quick`; all other fields retain the
semantics defined by `RegenerateRequest`.


## Example Usage

```typescript
import { AgentRegenerateRequest } from "@pipeshub-ai/sdk/models";

let value: AgentRegenerateRequest = {
  modelKey: "05438a37-68f2-4641-a8dc-6c47e63278ca",
  modelName: "gpt-5.6-luna",
  modelFriendlyName: "mini",
  chatMode: "quick",
  timezone: "Asia/Calcutta",
  currentTime: new Date("2026-05-11T15:43:21+05:30"),
  tools: [
    "jira.create_issue",
    "confluence.search_content",
  ],
};
```
