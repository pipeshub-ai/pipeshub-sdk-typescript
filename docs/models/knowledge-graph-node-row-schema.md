# KnowledgeGraphNodeRowSchema

One row in a navigate listing. Carries the identity fields of
KnowledgeGraphNodeRefSchema (inlined rather than composed, so this
object can stay closed) plus display detail.


## Example Usage

```typescript
import { KnowledgeGraphNodeRowSchema } from "@pipeshub-ai/sdk/models";

let value: KnowledgeGraphNodeRowSchema = {
  id: "<id>",
  name: "<value>",
  nodeType: "<value>",
  subType: null,
  isRecord: true,
  hasChildren: true,
  detail: "<value>",
};
```
