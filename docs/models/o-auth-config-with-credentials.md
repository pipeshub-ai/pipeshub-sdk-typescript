# OAuthConfigWithCredentials

An OAuth configuration as `GET /oauth/{connectorType}/{configId}` returns it. An admin
gets `config` with the stored credentials; any other caller gets the same object without `config`.


## Example Usage

```typescript
import { OAuthConfigWithCredentials } from "@pipeshub-ai/sdk/models";

let value: OAuthConfigWithCredentials = {
  connectorType: "Confluence",
  iconPath: "/icons/connectors/confluence.svg",
  appGroup: "Atlassian",
};
```
