# AuthStep

A single step in multi-factor authentication flow

## Example Usage

```typescript
import { AuthStep } from "@pipeshub-ai/sdk/models";

let value: AuthStep = {
  order: 2673.49,
  allowedMethods: [
    {
      type: "microsoft",
    },
  ],
};
```
