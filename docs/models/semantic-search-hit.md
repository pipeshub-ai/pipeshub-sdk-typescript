# SemanticSearchHit

One search hit returned by the retrieval service. Most hits use string `content`;
table or grouped blocks may serialize structured payloads as JSON arrays.
Listed fields are the documented contract; extend this schema when new stable top-level keys are introduced.


## Example Usage

```typescript
import { SemanticSearchHit } from "@pipeshub-ai/sdk/models";

let value: SemanticSearchHit = {};
```
