# AdminPatListItem

A personal access token as seen by an org admin — extends
`PatListItem` with who it belongs to, since an admin is looking
across every member's tokens rather than just their own.


## Example Usage

```typescript
import { AdminPatListItem } from "@pipeshub-ai/sdk/models";

let value: AdminPatListItem = {
  id: "<id>",
  name: "<value>",
  scopes: [],
  createdAt: new Date("2024-09-23T09:04:06.721Z"),
  expiresAt: new Date("2026-10-17T18:53:20.248Z"),
  userId: "<id>",
  ownerDeleted: false,
};
```
