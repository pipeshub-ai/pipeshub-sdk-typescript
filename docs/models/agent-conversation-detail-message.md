# AgentConversationDetailMessage

Message shape returned by `GET /agents/{agentKey}/conversations/{conversationId}`.
The response spreads the stored message document and replaces
`citations` with populated citation objects.


## Example Usage

```typescript
import { AgentConversationDetailMessage } from "@pipeshub-ai/sdk/models";

let value: AgentConversationDetailMessage = {};
```
