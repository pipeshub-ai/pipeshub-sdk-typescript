# WebSearchProviderItem

Web search provider configuration item returned by getWebSearchProviders

## Example Usage

```typescript
import { WebSearchProviderItem } from "@pipeshub-ai/sdk/models";

let value: WebSearchProviderItem = {
  provider: "exa",
  providerKey: "<value>",
  configuration: {
    "key": "<value>",
  },
  isDefault: false,
};
```
