# Project

A workspace that groups related assistant and agent conversations
under a shared name, instructions, knowledge scope, tool
selection, and its own hidden Collection of uploaded files. See
the `Projects` tag description for the sharing model.


## Example Usage

```typescript
import { Project } from "@pipeshub-ai/sdk/models";

let value: Project = {};
```
